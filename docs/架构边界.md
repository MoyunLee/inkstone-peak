## 1. 硬约束（先记住这七条）

| 约束 | 落点 | 违反的后果 |
|---|---|---|
| **纯静态、运行期零请求** | 页面只 import `.content/*.json`；无 fetch / 无后端 | — |
| **内容在构建期校验，失败即中止** | `scripts/content/**` + zod + 交叉规则 | 构建非零退出，打印中文报错 |
| **正文预渲染**（爬虫 / 无 JS / 首帧都看得到内容） | `src/entry-server.tsx` + `scripts/pre-render.ts` | 硬闸拦截（见 §5） |
| **界面中文零字面量** | `scripts/gate-cn.ts` 扫 `src/components` + `src/pages` | 构建失败 |
| **调试语句不进产物** | `scripts/gate-debug.ts` 扫 `src/`（`console.*` / `debugger`） | 构建失败 |
| **只用系统字体栈** | `src/styles/tokens.css` 三个字体令牌 | 无 `@font-face`、无 `/fonts/` |
| **产物可静态托管**（目录索引语义） | `dist/<路径>/index.html` + `dist/404.html` | 走 SPA 回退式托管会让首帧错页（见 `40`） |

## 2. 技术栈与环境

| 层 | 选型 | 说明 |
|---|---|---|
| 运行 | React 19 · react-router-dom 7 · lucide-react（图标） | SPA，无 SSR adapter；**运行期不 hydrate**，`createRoot` 接管 |
| 构建 | Vite 8 + `@vitejs/plugin-react` | 纯静态；预渲染自管（`vite build --ssr` + 自写注入） |
| 样式 | Tailwind CSS 4（`@tailwindcss/vite`）+ 手写 CSS 分片 | Tailwind 只用基础重置与便当盒网格工具类 |
| 内容 | `gray-matter`（front-matter）· `js-yaml`（site.yml）· `markdown-it`（正文）· `zod` 4（校验） | 全部构建期依赖 |
| 素材 | `sharp`（仅 `scripts/assets.ts` 用） | 程序化底图/云雾/噪点/品牌印记；`media` 步**不含** sharp |
| 运行时 | Node ≥ 23.6（`.nvmrc` 钉 24） | **原生类型剥离直接跑 `.ts`**：无 ts-node / tsx，脚本入口就是 `node scripts/xxx.ts` |
| 类型 | TypeScript 5.9 | `erasableSyntaxOnly`（禁 enum/namespace）· `allowImportingTsExtensions` · `moduleResolution: bundler` · `strict` + `noUncheckedIndexedAccess` · `resolveJsonModule`；`include: ["src","scripts"]` |

开发环境的四条纪律：

1. **相对 import 必须带扩展名**（`.ts` / `.tsx`）——原生跑 TS 的前提。
2. **没有 paths / alias**：只有相对路径。
3. `.npmrc`：`cache=.npm-cache`（缓存钉在工程内，不写用户目录）· `audit=false`（审计改由 `checklist` 显式跑）· `loglevel=warn`（压掉 npm 12 每步一行的 `npm notice run …`）。
4. `tsc --noEmit` 依赖 `.content/*.json` 已生成——干净 clone 先跑 `npm run content`（或直接 `npm run build`）。

## 3. 运行层结构

### 3.1 外壳与两个入口

| 文件 | 角色 |
|---|---|
| `index.html` | **预渲染壳**：固定替换锚点在这里（`<html lang>` / `<title>` / `description` / `canonical` / `#prerender` 槽）。手改壳里的值无意义——每次预渲染都会被覆写 |
| `src/main.tsx` | 客户端入口：`createRoot` + `BrowserRouter` + `StrictMode`，引入 `styles/index.css` |
| `src/entry-server.tsx` | **构建期** SSR 入口：`renderToPipeableStream` + `onAllReady` 取整段 HTML；`StaticRouter` 定位。超时 20s；树内错误即 reject。客户端 bundle 从不引用它 |

### 3.2 路由（`src/routes.tsx`）

```
/            Home              /blog        BlogList
/portfolio   PortfolioList     /blog/:slug  BlogDetail
/portfolio/:slug PortfolioDetail   /footer  FooterPage
/about       About             *           NotFound
```

路由树顶层还挂三枚**纯副作用组件**，外加一枚全站覆层（`Lightbox`，不做路由、只做委托与渲染）：

| 组件 | 作用 |
|---|---|
| `ScrollReset` | 仅 pathname 变化时执行：`unlockAllNav()` +（无 hash 时）回顶；挂载首跑不碰 |
| `RouteMeta` | SPA 换页改写 `document.title` / `lang` / `description` / `keywords` / `robots` / `canonical`——口径与构建期**共用同一个函数**（§6） |
| `DropPrerender` | React 首次提交后从 DOM 摘掉 `#prerender`（隐去由 CSS 在同一帧完成） |
| `Lightbox` | 点图放大层（全站覆层，**不是**路由页面）：document 上的 click **委托**——正文是构建期直出的 HTML，React 不认识那些 `<img>`，委托是唯一能覆盖全站的一处；链接里的封面（卡片 / 轮播）放行走原跳转 |

**页面清单不止这一处**：预渲染页面、`sitemap.xml`/`rss.xml`、页面 meta 全部从 `site.yml nav` 派生；`routes.tsx` 是 React Router 需要的代码级路由表。加一个 nav 条目 → feed/meta/预渲染份数自动 +1；但**该路径要真渲染出内容，仍须在这里挂 Route + 写页面组件**（详见 `30`）。

### 3.3 页面装配

| 页面 | 结构（顺序） | 数据 | 要点 |
|---|---|---|---|
| `Home` | Header → 进度条 `.scroll-prog` → main → `home.sections` 顺序映射段组件（Hero / Featured / BlogPreview / AboutPreview / SiteFooter）→ SideTabs | `useSite()` + `src/site/sections.ts` 的 id→组件表 | 调 `useHashScroll()`；不支持 `animation-timeline: scroll()` 时用 rAF 写进度条；五段**静态注册**（懒加载会毁掉预渲染，见 §5） |
| `PortfolioList` | Header → FadeCarousel → CaseGrid → SiteFooter | `works` | 轮播 = `carousel===true && cover` 的作品，截到 `max_slides`；纯图 |
| `PortfolioDetail` | 未命中 → `<NotFound/>`；命中 → `<ArticleDetail entry={w} />`——**页面只剩取数与 404 分流**，页面本体（顶图槽 / 题头 / 正文 / 嵌入 / 侧栏）全由外壳按数据算 | `workBySlug(slug)` | 博文在 `/portfolio/:slug` **恒 404**（类型分流）；视频走 `VideoHero`（失败态＝封面 + 重试 + 用系统播放器打开，不再是死图）；嵌入走 `EmbedHero`——iframe 属性母版住 `lib/data/embed.ts`（`allow` 逐项放行 + `referrerPolicy`，**不给 `sandbox`**：WebKit 252755 会让 MSE 读不到，移动端点不动，闸门 ⑦ 守着），顶部槽 `eager`、分节 `lazy`；**手机那一档封面即入口**（封面 + 播放环 + 「新窗口观看」同一个链接，点了去平台页，不装播放器——第三方 iframe 会被部分自带浏览器整块拦掉），桌面才在本站装播放器 |
| `About` | Header → `section#about.bento-grid` → AboutIntro（hero + intro + pursuit + skill）→ CareerCard? → GameStatsCard? → PlaceCard? → SiteFooter | `site.about` + `src/lib/data/about.ts` 的守卫 | 三卡**缺省即隐藏**（无 timeline / gameLog / location 就不渲染） |
| `BlogList` | Header → Heatmap（`heatmap` 段存在时）→ ArticleGrid（全量，不截断）→ SiteFooter | `articles`（全量含作品）+ `heatItems` | 热力图数据 = `lib/data/content.ts` 的 `heatItems`：全站文章（含作品）**发布日 + 更新日各 1 条**（`updated` 缺省或与 `date` 同日只记 1 条；故每篇 1~2 条） |
| `BlogDetail` | 未命中 → `<NotFound/>`；命中 → `<ArticleDetail entry={b} />`（与案例页**同一个外壳、同一份配方**） | `postBySlug(slug)` | 作品在 `/blog/:slug` **恒 404**（类型分流）；内容槽（`links` / `video` / `embeds`）两型同权（2026-09-23） |
| `Footer` | Header → main → SiteFooter | `useSite()` | 独立传音页（与首页第五段同一组件） |
| `NotFound` | main → `h1`（`notfound.line`）→ 印章按钮（`notfound.cta`） | `useSite()` | 不渲染 Header / 页脚 / 题签；预渲染时带 `noindex` |

### 3.5 数据层（`.content/*.json` → `src/lib/data/*`）

构建期产出三份 JSON（外加报告），运行层**静态 import**，零 fetch：

| 文件 | 内容 | 消费者 |
|---|---|---|
| `.content/site.json` | 校验后的整份 `site.yml` | `lib/data/site.ts` |
| `.content/posts.json` | 文章有效值数组（front-matter × Post Settings 已解析、正文 HTML、标题清单） | `lib/data/content.ts` |
| `.content/drafts.json` | `draft: true` 的文件清单（只报数，不进页面/feed） | `checklist` |
| `.content/media-report.json` | 媒体闸的 `urls / warnings / errors` | `checklist` |

```ts
useSite()            // 整份站点数据（a11y 缺省已归一成 {}）
sectionById(s,'blog')// 取首页段
posts / articles     // 全量文章（中心库）
works                // 构建期判为作品的那些（判据 = kind）
workBySlug(slug) / postBySlug(slug)
```

`src/lib/types/*` 是唯一契约面：`ArticleCommon` 为两型共用的**全必填**字段集（可空者用 `| null` 表达），`WorkArticle` 追加 `kind: 'work'` + 作品字段，`PostArticle` 追加 `kind: 'post'`。
JSON 导入用 `as unknown as` 断言（只因字面量会被拓宽成 `string`）；**真实漂移由 `scripts/content/contract.ts` 在 `tsc` 阶段拦下**。

### 3.6 导航心器（`src/lib/nav/`）

双导航（顶栏 + 右侧题签）共用同一事实源与心器。

| 文件 | 职责 | 关键实现 |
|---|---|---|
| `nav-sync-core.ts` | **纯决策层**（零 DOM、零 React，可 node 直测） | `resolveActive` 五级解析：① spy 段在 `main` 域 → ② path 命中 `detailPrefix`（详情页前缀固定激活）→ ③ hash 命中 `module` 且该段在 `any` 域 → ④ 非详情条目的 path 相等 → ⑤ `-1`。`normHash` 把 `#home` 归一为空（首页锚点不参与在场判定） |
| `nav-sync.ts` | 引擎：IO 探针 / MO 懒挂 / URL 写闸 / 点击律 | `useSyncExternalStore` + 模块级单例（**同一页面只能调用一次**）。IO `rootMargin: '-45% 0px -45% 0px'` 只改高亮；URL 写入需「load+400ms、用户已动手、候选段全量挂载」三闸齐备，再 200ms 去抖 `replaceState`；未在场宽限 1600ms 后强制解锁。点击律：**本页命中**才不跳转（详情页条目以「落在它自己的列表页」为判据，如 `/portfolio`；有锚滚锚、无锚回顶），在详情页里点同族条目（`/portfolio/<slug>` → 观山）**照常回列表**，跨页跳转前上锁 |
| `navlock.ts` | 共用锁表 + 用户行为闸 | 250ms 连击吞 · 800ms 跳页锁 · `markActed/hasActed/resetActed`（5 个人机事件：wheel / touchstart / keydown / pointerdown / click） |

### 3.7 效果层（`src/fx/`）

| 文件 | 事实 |
|---|---|
| `ink-field.ts`（272 行） | 唯一导出 `createInkField(canvas): dispose`。粒子数上限 **移动端 2800 / 桌面 6500**（`innerWidth < 640` 判定移动端），采样步长 6/4；回位弹簧 `K=0.012`、阻尼 `DAMP=0.94`；指针斥力半径 220/150；**指针坐标 = 画布局部坐标**（`toLocal` 唯一换算处：`getBoundingClientRect` 一处吸收滚动 / 页内偏移 / DPR——画布随文档滚动，直接用 `clientX/clientY` 会让散开中心偏高一个 scrollY，2026-09-19 实测滚 260px 偏高 254px）；指针事件挂**山门段**而非画布（画布上还压着 `.hero-copy`，悬停标题也要跟手），滚动时按最近视口坐标重算；剑气（pointerdown）= 沿**指针划动方向**扫过（无位移则竖直下扫；原实现方向恒竖直，2026-09-19 实测水平划动时位移「沿划动 0.84」→ 改后「垂直划动 1.26」），每页 3 条、冷却 2000ms、寿命 300ms；透明度上限 0.92；DPR 上限 2（移动端再乘 0.75）；reduce-motion 时**不启动 rAF**，只静态成画一帧；出视口 / 标签页隐藏即暂停 |
| `scene-data.ts`（137 行） | 程序化「数据山」：`OFF_W=960 / OFF_H=560`，种子 `20260905`，三层山脊（中点位移，rough 0.58）+ 每层 260 个斑点；导出 `sampleScene(mobile,pitch)` / `fadeAt(x,y)`。`scripts/assets.ts` 用它预烘无 JS 底图 `hero-base.png`（同一份数据，两处消费） |

首页 `Hero` 对 `fx/ink-field` 用**动态 import**（真正的重货）；段落组件本身一律静态注册（§5）。

### 3.8 详情页外壳（`ArticleDetail`）——**作品与博文只有这一个**

两型**同一个外壳、同一份配方、同一套骨架类**：页面文件只剩「按 slug 取一篇 + 取不到走 404」，
其余全部由外壳按文章数据算。外壳**不认识 `kind`**——类型判断只活在 `articleRecipe.tsx` 与构建期。

| 落位（自上而下） | 出处 | 内容规则 |
|---|---|---|
| 顶图槽 `hero` | `articleHero()` | **有视频出视频 → 有图出图 → 都没有不出**；`top_img` 已在构建期含「缺省回落 `cover`」与「显式 `false` 关闭」三态，两型都读它。16:9、方角、独占版心 |
| 标题 → `.bd-rule` | — | 题头只有标题一条线：提要与元信息都收进侧栏，两处同时出就是重复。唯一例外＝`aside: false` 的篇目，此时回落到 `articleMeta()` 的元信息行 |
| 目录 | `tocPlacement()` | `toc: false` → 不出；`aside && !toc_style_simple` → 进侧栏；否则内联在正文上方。**两型同走 `toc.*` 默认值**（原 `portfolio.toc` 已退役） |
| 嵌入槽 `preBody` | `articlePreBody()` | 第三方嵌入 + 外链，两样都没有就整块不出 |
| 正文 | `PostBody` | 直出 HTML + 代码框折叠 + 公式/播放器钩子（有效值构建期已解析） |
| 版权槽 `postBody` | `articlePostBody()` | 版权模块 + 评论挂载点，开关没开就都不出 |
| 侧栏信息卡 | `ArticleAside` + `articleAsideRows()` / `articleAsideTags()` | **只框信息**（`.pa-card`：发丝界 + 圆角 + 纸色微底）：作者 / 提要 `.pa-desc`（`description`，署名之下）/ 行（发布 · 更新于 · 分类 · 周期，受 `post_meta.post` 管）/ 标签胶囊。目录在**卡外**自成一块（见下一行）；aria 名两型同一枚（`a11y.post_aside_label`） |
| 侧栏目录 | `PostToc variant="aside"` | 与卡并列的独立块（自己的强调色左线 + 纸色微底）；条目多时**目录自身**滚，不把信息卡一起顶高 |

- 配方只有一份，住 `src/components/ui/article/articleRecipe.tsx`。2026-09-21 收口前两页各写一份：博文没提要、没嵌入与版权槽，作品没日期与分类，同一条 front-matter 长出两套页面。
- `articleTags()` / `articleAsideTags()`：作品以 `site.yml` 的 `blog.work_tag` 打头（与归档卡同一公式）；类型标记词构建期已剔除，运行层只剩 `kind`。侧栏胶囊与回落行取同一份值，`post_meta.post.tags: false` 一起关。
- `post_meta.post`（`date_type` / `categories` / `tags` / `label`）自此管**侧栏**这一处（元信息只剩这一处）；`date_type` 的口径由 `metaDates()` 一处实现，侧栏行与回落行共用。
- 作品专属数据（`video` / `period` / `embeds` / `links`）由 `workPart()` 取——契约里博文没有这几个键，取不到即按空处理。
- 页面根节点写内联变量：`--post-accent`（= `main_color`，缺省回落印朱）与 `background`（构建期已限成安全值）。
- 栅格：`.bd-layout`（就是 `<article>` 本体）在窄屏是单列，**DOM 顺序恒为「`.bd-head` 标题区 → `.post-aside` 侧栏 → `.bd-body` 正文**」——窄屏单列即这个阅读顺序（标题 → 信息卡与目录 → 正文）；≥1024 用命名栅格区 `'head side' / 'body side'` 把侧栏整列右移。
- 侧栏吸顶与目录自身滚动由 CSS 负责（见 `20-设计规范.md`）。

### 3.9 Hooks

| Hook | 行数 | 行为 |
|---|---|---|
| `useMotionSafe` | 24 | 读 `prefers-reduced-motion`；**首渲染固定 false**（值不进 markup，SSR 安全），挂载后同步并在 change 时更新 |
| `useHashScroll` | 43 | 让 URL hash 真正落地：命中即 `scrollIntoView({behavior:'instant'})`（显式 instant，防继承全局 smooth）；未命中用 MutationObserver 等元素出现，上限 2000ms |
| `useMasonry` | 52 | 观山瀑布流：`UNIT=8`（**必须与 CSS `grid-auto-rows: 8px` 一致**），按卡高换算 `grid-row-end`；量高期间临时 `align-items: start`；ResizeObserver + resize + `fonts.ready` 重算，rAF 合帧 |
| `useTocSpy` | 64 | 目录当前章节：探针线 = `--nav-h` + 16，取「滚过这条线的最后一段」；触底取末条；依赖键用 `ids.join()`（避免每帧拆装监听） |

## 4. 构建链（九步）

```
npm run build
  = content → media → assets → gate → tsc --noEmit → vite build → ssr → prerender → feeds
```

| 步 | 命令 | 输入 | 输出 | 失败行为 |
|---|---|---|---|---|
| content | `npm run content` | `site.yml` · `source/posts/**` · `src/site/sections.ts` | `.content/{site,posts,drafts}.json` | error → exit 1（中文报错 + 逐字段翻译）；warning 继续 |
| media | `npm run media` | `source/images` `source/video` | `.content/media-report.json`（**只校验不搬运，不吃 sharp**） | 单文件 >25 MiB → exit 1；编码/faststart → 警告（只提醒，不阻塞） |
| assets | `npm run assets` | `src/fx/scene-data.ts` + `tokens.css` + `.content/site.json` | `source/site/{noise.webp,hero-base.png,mist-a.png,mist-b.png,favicon.svg,apple-touch-icon.png}` | 异常 → exit 1 |
| gate | `npm run gate` | `src/components` `src/pages`（中文闸）· `src/`（调试闸） | — | 命中 → exit 1 |
| tsc | `npx tsc --noEmit` | `src` + `scripts` + `.content` | — | 类型错 → 非零 |
| vite build | `vite build` | `index.html` `src/` + `publicDir: source/site` + `source/{images,video}`（插件直写） | `dist/` | 非零（含 `source/site` 发布白名单闸） |
| ssr | `npm run ssr` | `src/entry-server.tsx` | `.ssr/entry-server.js`（gitignore） | 非零；只给 prerender 用 |
| prerender | `npm run prerender` | `dist/index.html` + `.ssr/` + `.content/` | 逐路由 HTML（**含正文**）+ `dist/404.html` + 覆写根壳 | 壳/锚点/`#prerender` 槽缺失、正文含迟到 Suspense 标记、路由数不符 → exit 1 |
| feeds | `npm run feeds` | `.content/` + `site.url` | `dist/{sitemap.xml,rss.xml,robots.txt}` | dist 未构建 → exit 1 |

### 4.1 内容管线（`scripts/content/`）

| 文件 | 职责 |
|---|---|
| `index.ts` | 入口：`--watch` 走常驻监听，否则跑一次 |
| `build.ts` | 主流程：读事实 → zod 校验 → 交叉规则 → 解析有效值 → 写盘 |
| `loaders.ts` | **递归**读 `source/posts`（`.md`；点开头目录跳过；返回 slug=文件名 + rel 路径）、占位归一与正文占位样式化 |
| `paths.ts` | 根路径 · markdown 渲染器（`html:false` / `linkify:false`）· 标题锚点规则 · **素材路径双向映射**（`toMediaUrl` / `masterPathFor`） |
| `post.ts` | front-matter × Post Settings → 有效值（`resolvePost`） |
| `checks.ts` | 首页段组件实现清单（**正则读 `src/site/sections.ts`**）· 内链/锚点校验 |
| `diagnostics.ts` | 报错收集与 `FIELD_CN` 字段中文翻译表 |
| `schemas/` | `site.ts`（22 节）· `article.ts`（统一文章契约 + `PORTFOLIO_TAG`）· `shared.ts`（复用件 + 嵌入白名单 + 素材路径归一） |
| `contract.ts` | schema ↔ interface 类型对账（tsc 阶段） |
| `watch.ts` | `content:watch`：监听 `site.yml` / `source/**` / `src/site/sections.ts`，150ms 去抖 |

**markdown 安全不变量**：渲染器 `html: false` + `linkify: false`，正文经 `dangerouslySetInnerHTML` 直出——`html: true` 等于执行 md 里的原始 HTML；要放开必须同时上 DOMPurify，不能只改这一个开关。

### 4.2 素材搬运（`vite.config.ts` 两个插件）

| 段 | 机制 | dev | build |
|---|---|---|---|
| `source/site/**` → `/**` | **Vite 原生 `publicDir: 'source/site'`** | 直供 | 整份拷进 `dist/` |
| `source/images/**` → `/images/**` | 插件 `staticFromSource`（`MIRRORS`） | 直读源目录（支持 Range） | `closeBundle` 直写 `dist/` |
| `source/video/**` → `/media/video/**` | 同上 | 同上 | 同上 |

两处安全细节（2026-09-18 修）：路径先 `decodeURIComponent` 兜错、再把反斜杠归一成 `/` 后逐段判 `..`（Windows 上 `..%5C..%5C` 曾能绕过）；`source/site/` 有发布扩展名白名单，违规即构建失败。
素材目录里的 `*.md` 说明文件**从不发布**（两处都跳过）。SSR 那次 build 不搬运。

### 4.3 日志三档（`scripts/quiet.ts`）

| 档 | 触发 | 输出 |
|---|---|---|
| 默认 | — | 仿 `hexo g` 报告：ASCII 横幅 + `Start processing` + `Files loaded in …` + 逐产物 `Generated:` + `N files generated in …`（N = `dist/` 交付清单） |
| 安静 | `BUILD_QUIET=1`（`npm run build:quiet`） | 成功零输出；拦截/警告照常出声 |
| vite 原样 | `VITE_BUILD_VERBOSE=1` | 让位 vite 英文进度（报告自动停） |

跨进程记账：content 步把「生成阶段起点」写进 `.content/.build-report`，feeds 步读它算总耗时。
全量原文清单（每条消息的出处与触发条件）见 `50-终端文案大全.md`。

## 5. 预渲染（本工程最核心的一段）

**目标**：首帧、无 JS 用户、爬虫看到的是**正文**，而不是空壳；JS 用户看到的是应用。

1. **正文**：`vite build --ssr src/entry-server.tsx` → `.ssr/entry-server.js`；`prerender` 逐路由 `render(url)`，把 SSR 串注入壳的 `<div id="prerender">` 槽。
2. **交接**：运行期**不 hydrate**，仍是 `createRoot`。壳里的 CSS 规则 `#root:not(:empty) ~ #prerender { display: none }` 在 React 首次提交的同一帧隐去预渲染块，随后 `DropPrerender` 摘除 DOM → 无闪烁、无重复、避开整类 hydration 不一致。
3. **硬闸**（`pre-render.ts`）：
   - 正文里出现 `<script` / `<template` / `<div hidden` → exit 1（迟到落定的 Suspense 会把正文藏进 inert template）。**这就是首页段落必须静态注册的原因**（`src/site/sections.ts` 顶部有完整缘由）。
   - 壳里 `#prerender` 槽缺失、`<title>` / `description` / `canonical` / `<html lang>` 锚点缺失 → exit 1。
   - 路由数对账：`nav 条目数 + 文章数 + 1(404)`，不符即 exit 1。
4. **幂等**：单跑 `prerender` 会先把上一轮注入的正文还原成空槽再注入；根壳最终被首页结果覆写。
5. **路由清单来源**：`nav[].route`（每条的列表页）+ 详情条目下 `posts[].to`（`to` 由 `detailPrefix` 派生）+ 404。**没有任何一份手写白名单。**
6. **本地预览语义必须与生产一致**：`vite preview` 默认走 SPA 回退，会把 `/portfolio` 这类目录路径喂成 `dist/index.html`（首帧 = 首页，预渲染等于白做）。`vite.config.ts` 的 `previewDirIndex()` 中间件补了目录索引改写（未知路径给 `/404.html`），**只挂 preview、产物零改动**。
7. **交付清单**（2026-09-19 实测）：`dist/` 共 **25 个文件 / 10 份路由 HTML**（5 个静态页 + 2 作品 + 2 博文 + 404），每份都带预渲染正文。

## 6. 元信息口径（`src/lib/meta/page-meta.ts`）

**一个函数，两个消费者**：构建期 `pre-render.ts` 写进各路由 HTML；运行期 `RouteMeta` 在 SPA 换页时改写 `document`。改口径只改这一处。

- 匹配顺序：① `nav` 条目（按 `route` 全量匹配）→ ② 文章落点 `to` 命中 → ③ 其余按 404 口径（`noindex` + `notfound.line`）。
- `title`：`<专名> · <site.title>`；专名 = `page_meta[路由 basename]`（缺键回落 `site.title`）；首页只有 `site.title`；文章 = `title · site.title`。
- `description` 取法是一张**策略小表**（`STATIC_DESC`，不是路径白名单）：`''/portfolio/about` → `site.description`；`blog` → 该段的 `intro`；`footer` → 该段的 `heading`；未列出的新页默认 `site`。
- `canonical`：`site.url`（去尾斜杠）+ 归一化路径。`keywords`：博文取 `keywords`，缺省用 `tags` 兜底，非空才插。
- `lang`：`site.lang`（缺省 `zh-CN`）。
- **零依赖**（不碰 DOM、不碰 node:），两侧才能共用。

## 7. 构建期校验

### 7.1 形状（zod，全部 `.strict()`）

- 三份契约：`siteSchema`（22 节）· `articleSchema`（统一文章契约）· `shared.ts` 复用件。
- 未知键、缺必填、类型不对都在 `npm run content` 被拦，报错走 `diagnostics.ts` 的字段中文翻译。

### 7.2 交叉规则（error 中止 / warn 继续）

| 项 | 规则 |
|---|---|
| slug | 文件名 kebab-case；**全站唯一**（跨子目录同名报两处路径） |
| 作品 | 至少 1 篇 `tags` 含类型标记，否则 error（首页观山段与 `/portfolio` 会空） |
| nav | `ink` 唯一 · `route` 基路径唯一 · `detailPrefix` 不撞车 · `module` ∈ 段 id 且唯一 · `isDetailPage` 与 `detailPrefix` 有无一致 |
| 首页段 | `id` 必须在 `src/site/sections.ts` 有实现（**幽灵项 = error**）；`sections.ts` 多出的段 = warn；`id` 重复 = error |
| about | 声明了 `anchors` 就必须含 `about` + `footer` 双锚点 |
| 地址 | `contact.email` 正则；`site.url` 合法 http(s)；社交键 `url` 须 null 或合法 |
| 内链 | `nav.route/detailPrefix`、`home.sections[].cta[].to`、`footer.cta.to`、`footer.portfolio_links[].to`、`footer.columns[].links[].to`、`notfound.cta.to` 须命中 nav 派生路由表；`/portfolio/<slug>` 不存在 → warn；带扩展名的路径改查 `source/site/` 落盘（缺失 → warn） |
| 锚点 | `/` → `home` 段 id；`/about` → `about.anchors`；其余路径不接受 fragment |
| 页脚 | 非 `brand` 栏必须给 `from`（nav/contact）或 `links`（键名须是 footer 下的链接表） |
| 素材存在 | `cover` / `top_img` / `video.src` / `video.poster` 校 `source/` 母版（http 跳过；`【占位】` 已归一故静默）→ 缺失 warn |
| 轮播 | `carousel: true` 却没有 `cover` → warn；候选数 > `max_slides` → warn |
| 双份编号 | 标题自带编号（`一、` / `3.1 `）× 自动编号生效 → warn |
| `relatedWork` | 悬空 → warn |

### 7.3 内容级安全闸

| 面 | 规则 |
|---|---|
| `links[].url` | 必须合法 `http(s)` |
| `embeds[].url` | 必须 `https://` + host 白名单（B站播放器 / 优酷 / 腾讯 / 抖音开放平台 / YouTube nocookie / Vimeo）；粘 B 站**页面**地址会被当场击落并给出播放器模板 |
| `background` | 只放行 `#hex` / 具名色 / `rgb()` / `hsl()` / 站内 `url(/…)`（CSS 注入面收口） |
| `main_color` | 必须 6 位十六进制、不可缩写 |
| `copyright_author_href` / `copyright_url` | `safeRef`：站内绝对路径或 `http(s)`（挡 `javascript:`） |
| `source/site/` | 发布扩展名白名单 |
| 正文嵌入（块级 `@[标签](播放器地址)`） | 与 `embeds[].url` 同三道闸；标签与地址进 iframe 属性前一律 HTML 转义（取证 `.shots/probe-xss-embed.mjs`：塞 `"><script>` 只出实体，0 个 `<script` 标签） |

**托管侧第二道（2026-09-23）**：根 `vercel.json` 的 CSP —— `script-src 'self'`（全站无内联脚本，故不收 `'unsafe-inline'`）· `frame-src` **恰好等于**上表那份嵌入白名单（`scripts/gate-headers.ts` 核对，多一个少一个都构建失败）· `object-src 'none'` · `frame-ancestors *`（**允许被友链站内嵌**，故不发 X-Frame-Options——发了会把 iframe 挡在门外）· `form-action 'none'`；另发 HSTS / nosniff / Referrer-Policy / Permissions-Policy 与 `/assets/*` immutable。

## 9. 类型契约与对账

- 契约三处：`scripts/content/schemas/*.ts`（运行期校验）· `src/lib/types/*.ts`（编译期类型）· `.content/*.json`（产物）。
- `scripts/content/contract.ts` 把 JSON 赋给运行层 interface，**由 `tsc --noEmit` 覆盖 `scripts/`**，字段有无 / 基类型 / 可空性不一致即报错（字面量拓宽用 `JsonView` 放宽）。
- `tsconfig` 的 `include: ["src","scripts"]` 是这条对账能生效的前提。
- **类型标记只有一处**（2026-09-19 收口）：判定住 `schemas/article.ts` 的常量，构建期把标记词从产物的 `tags` 里剔除，运行层按 `kind` 分流——`site.yml` 里**没有**这个键，也就不可能分叉。

# 架构边界 —— 改什么需要动代码

## 零代码（改配置 / 内容）

| 想改 | 改哪里 |
|---|---|
| 站名 · 描述 · 域名 | `site.yml` `site:` |
| 导航增删改 / 雅词 / 详情前缀 / 页面路径 | `site.yml` `nav:`（五字段）。预渲染、`sitemap.xml`/`rss.xml`、页面 meta、文章落点 `to` 全由它派生——改 `route`/`detailPrefix` 只动这一处 |
| 首页各段文案 / 顺序 / 显隐 | `site.yml` `home.sections` |
| 作品 / 文章 | 加 md 到 `source/posts/portfolio/`（作品）或 `source/posts/blog/`（博文）即可——**子目录可再任意嵌套**，构建期递归读取，不改 slug/类型/URL；类型由 tags 里的标记判定——`tags: [portfolio, ...]` = 作品（走 `/portfolio/<slug>`，可选用作品字段），不带该标记 = 博文。`/blog` 是中心库展示全部，`/portfolio` 是同一份数据的标记子集。**首页=全量作品**，无精选开关，先后由各篇 `date` 倒序决定 |
| 关于页事实（生涯 / 游戏阅历 / 坐标 / 锚点） | `site.yml` `about:`（2026-09-16 由 `content/about` 并入） |
| 技能组 | `site.yml` `about.skill_groups` |
| 页脚链接（含简历 PDF） | `site.yml` `footer.columns[].links`（键名或内联）；文件放 `site/source/site/` |
| 社交平台 | `site.yml` `contact:`（email 外随便加键） |
| 页脚四栏 | `site.yml` `footer.columns` |
| 文章默认值 / 目录 / 版权 | `site.yml` Post Settings 各节 |
| 无障碍与可见小字 | `site.yml` `a11y:`（键可缺） |
| 配色 / 间距令牌 | `src/styles/tokens.css` 等 |

> 内链白名单从 `nav` 派生 —— 加一行即让指向该路径的链接合法。

## 必须写代码

| 想改 | 要动哪 |
|---|---|
| 新增首页版块 | 写组件 → `src/site/sections.ts` 注册 → `site.yml` 加段 → `nav` 挂 `module` |
| 新增页面类型 | `src/routes.tsx` 加 Route + 写页面组件（页面清单 / meta / sitemap 会跟着 `nav` 自动出）|
| 交互 / 动效 | `src/lib/**`、`src/fx/**`、`src/styles/*.css` |
| 页面元信息口径（title/desc/canonical） | `src/lib/meta/page-meta.ts`（构建期与运行期共用一份，勿在别处再写一遍） |
| 预渲染正文 / 交付件 | `src/entry-server.tsx`、`scripts/pre-render.ts`、`scripts/feeds.ts` |
| 字体 | 全站**统一微软雅黑**（2026-09-18），仍是**系统字体栈**、零下载（20 §1）——不引入外来字体文件，改字体只动 `tokens.css` 的字体令牌 |
| 构建期校验 / 流水线 | `scripts/**` |
| 多语言 | 未支持 |

组件内不允许注释外的中文字面量（`gate-cn.ts` 扫 `src/components` + `src/pages`）。

## 缺省即隐藏

`about.gameLog` `about.timeline` `about.location` `about.anchors` `about.skill_groups` · `about.*` 文案键（除 `hero_title`）· `portfolio.carousel` · `heatmap` · `blog` · `contact` 任意社交键 · `a11y` 任意键 · `footer.columns[].links` 内联数组。

## 构建链

`content → media → assets → gate → tsc → vite build → ssr → prerender → feeds`

- **content**：zod + 交叉规则（nav 契约 / 内链 / 锚点 / 素材存在），失败即中止
- **media**：`source/{images,video}` 媒体闸（体积/编码/faststart，不含 sharp）——**不搬运**；搬运由 vite 插件 `staticFromSource` 负责（dev 直供、build 直写 dist）
- **assets**：唯一吃 sharp 的一步（程序化素材 + 品牌印记 `favicon.svg`/`apple-touch-icon.png`：印文取 `site.yml`、色与字族取 `tokens.css`）
- **gate**：`gate-cn.ts` 中文闸
- **tsc**：类型闸；`scripts/content/contract.ts` 对账 schema ↔ interface
- **ssr**：`vite build --ssr src/entry-server.tsx` → `.ssr/`（只给 prerender 用）
- **prerender**：逐路由注入**正文**（SSR 串进 `#prerender` 槽）+ title / description / canonical / keywords
- **feeds**：`sitemap.xml` / `rss.xml` / `robots.txt`（域唯一源 = `site.url`）
- 另挂 `checklist` `glyphs` `preview` `clean`（`clean` = `hexo clean` 对应物：删 `dist/` `.ssr/` `.content/`；`clean:all` 再加 vite 缓存 / `.npm-cache/` / `.shots/`）
- 输出：默认出仿 `hexo g` 的构建报告（横幅 + `Start processing` + `Files loaded in` + 逐产物 `Generated:` + `N files generated in`，清点口径 = `dist/` 交付清单）；`npm run build:quiet`（`BUILD_QUIET=1`）回到成功零输出；`VITE_BUILD_VERBOSE=1` 出 vite 原样英文。见 `scripts/quiet.ts`

## 目录

| 目录 | 职责 |
|---|---|
| `site.yml` | 话术唯一源 |
| `source/` | 条目与素材母版（`posts/` `images/` `video/`；素材命名规范见 `source/images/README.md`）|
| `source/site/` | 站点根静态件（favicon / apple-touch-icon / hero-base / mist / noise；手工件如简历 PDF）；经 Vite 的 `publicDir` 直出 |
| `scripts/` | 构建期引擎 |
| `src/` | 运行层 |
| `.content/` `dist/` | 生成物（gitignore） |
